## 分组判定（A 内核 / B 工具 / C 会话压缩 / D LLM / E 能力面 / F 概念面 / G UI）

### A. cordis 内核 / agent 主循环

1. **条件工具 step admission**（rc.2，core 9d0c97b9d2）——`ctx.tools.register(def, { when })` 加同步/异步条件，AgentLoop 每 step 在 prompt 组装前一次性 resolve 出 `ResolvedToolSet`，统一决定声明/dispatch/嵌套调用；条件抛错整个 turn 以 `TOOL_ACTIVATION_FAILED` 结束。收益示例：`exit_plan_mode` 只在真进过 plan 的会话声明。指针 `packages/core/tools/`。→ **值得搬**：mini 工具静态全量声明，此机制省 token 且防误用；中工程
2. 工具执行器插件化（native/PTC executor 拆独立插件 + ToolExecutionPipeline）——mini 无 PTC，学"执行模式与注册分离"方向即可
3. **agent-loop series-start 前缀规则**（2676c67f32）——文本未变时系列开头不得重写 prompt 前缀。→ 零成本写进 snapshot 回归纪律
4. timer wrappers（ctx.throttle/debounce 返回 void、dispose 后失效）——mini 若有同类包装对齐类型，小补丁
5. store-owned session 写保护（进 store 前后拒写、失败创建留可 resume 历史）——对应 mini 创建/resume 窗口加固，小
6. Node 24 门槛 / projection 重构——mini 无此层，不需要

### B. 工具面

- **apply_patch**（本窗口唯一新工具，新包 `packages/fs/fs-patch/`，实测 parse.ts 175 行、src 共 350 行）——Codex 风格整补丁：一次调用多文件 Add/Delete/Update+Move；纯函数 parsePatch/applyHunks，LF 归一 + 四轮宽松匹配（精确→去尾空白→去两端空白→Unicode 标点映射）；失败返回结构化数据不抛；工具壳 53 行默认 opt-in off；参考实现 OpenAI Codex rust-v0.158.0（Apache-2.0 归属保留）。→ **值得搬**：与 Edit/Write 互补多文件大改，纯函数可照抄配快照场景；中工程
- 取消的 PTC 调用返回 `ABORTED` 而非失败（"用户取消≠工具失败"）——可参考小规则

### C. 会话 / 持久化 / 压缩（mini 唯一"长会话必炸"缺口）

- **compaction 体系**（compaction-basic src ~1,750 行：region 600 / index 476 / config 362 / summarizer 221 + tool-result-pruner + image-offload + /compact）四条核心：
  ① 单一 tokenMeter 统一定价（触发/保留/校验）
  ② 日志 bracket 即事务：`compaction/start` 落盘 → await 摘要 → 复验 → `compaction/summary`+替换 → 收尾
  ③ 摘要请求逐字节重放 warm prefix（system prompt/工具/被压缩段原样）——与我们 snapshot 锚定同源思想
  ④ `summarize()` 唯一子类钩子；触发 `floor(min(W×0.8, W−O−65536))`，保留最新 16% 原文；溢出=压缩后重试；换模型前压力检查（失败报 `MODEL_SWITCH_COMPACTION_FOUND`）
  会话 JSONL 始终全量未压缩。指针 `packages/compaction/compaction-basic/README.md`（机制写得极全）。→ **值得搬**，拆两期：先 pruner（小补丁零模型调用），再最小核 ~800 行
- **durable checkpoint**（rc.2 起 sdk-minimal）：模型请求/顶层工具执行前必须等 JSONL flush 成功，失败即停。→ 小补丁，加固 resume 正确性
- independent-session-forks（fork 不记 parentSession，subagent 用 origin 判定）——现在不需要，做 subagent 时记住 fork≠subagent
- session-model-selection（模型选择钉在 step 准备并持久化）——mini resume 可顺手学
