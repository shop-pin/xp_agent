# SC2：指标原语库 + 公式解释器（2026-11-01）

总纲 §三 L2/L3 层。交付 = TDX 公式体系的心脏：16 个原语 + 20 个内置函数 +
词法/语法/编译/求值四段解释器。

## 设计决策

**1. 两层值域：Series（数值，头部空窗 null）与 Cond（boolean，null=false）。**
TDX 语义：窗口不满画不出（MA 头部 null）；选股语义"无效不选出"（比较/CROSS
遇 null = false，保守方向）。条件进算术按 0/1 收缩（TDX 同款，金例 7 钉住）。

**2. EMA/SMA 全序列递推 + 首根播种。** TDX 的 EMA 从第一根有效值开始递推
（不是用 N 根 SMA 播种）——KDJ 依赖的 SMA(X,3,1) 同款（金例 11 手算锚）。

**3. MA 滚动窗口遇 null 归零重凑。** K 线本体无内部空窗（停牌日没有 bar），
此分支只在指标叠指标（上家带头 null）时触发——窗口含无效=无效，TDX 画不出
的同款语义。

**4. 解释器 = 编译一次逐票求值。** AST 预编译（loadFormula 静态检查全过），
runFormula 只做向量运算——全市场逐票求值的性能前提。窗口参（MA 第 2 参等）
**编译期强制常量**（字面量或 params 名）——TDX 允许变量窗，v1 收紧为可静态
检查的形状（值得，换来坏公式加载期全拦截）。

**5. 坏公式加载期拒装清单**（全部点名报错）：缺分号 / 未知函数 / 未知名字 /
缺 XG / **双 XG=变量重复定义**（加载期拒，不是"最后一行生效"——比计划写的
语义更严，测试钉住）/ 变量重复 / 窗口参表达式 / 参数未提供 / 注释未闭合 /
非法字符。

**6. 中文标识符合法**（`一-龥` 进 IDENT_RE）——TDX 公式生态大量中文名，
金例 3 钉住。顺手抓出我自己过严的输出名正则（拒绝中文输出）并删除。

## 金例与手算（15 金例 + 10 坏公式 = 25 ≥ 20 达标）

- 金叉手算（金例 1）改过一次 fixture：**上涨序列里 MA3 永远在 MA5 上方，
  根本不存在金叉**——交叉语义只能在"先跌后涨"里出现。手算时要先问形态
  存不存在，再算位置。
- CROSS 昨位双侧必须有效：MA5 在 idx3 还是 null → idx4 的"上穿"不成立
  （金例 1 第一版手算踩的就是这个）。
- 除零语义：`C/0` → null → 后续比较 false（金例 8）。除零不炸是解释器
  对免费数据源的礼貌。

## 翻车记档

- **手算错四连**（LLVBARS 最低位当天=0 算成 2；金例 1 上涨无金叉；金例 12
  收盘没真破前高；金例 8 没构造出除零）——引擎全逮住。"手算名次错"是本仓
  教学面的经典家族（S5/S11/S13 各一次），这次一次章连中四元：**期望值必须
  逐项落笔、形态存在性先于位置计算**。
- TS 收窄三连：parsePrimary 尾部对已排除类型再取属性（`never`）；stdImpl/sum
  的 null 赋值 hack（改显式 hasNull 标志）。
- 测试名里 `Y'` 的撇号打断字符串字面量——中文注释里的技术记号要避开引号。
