# 移动止盈固化：exit.trailingStopPct（2026-10-31 下午档）

离场节的最后一块空白。one-pager 缺口清单第 1 条（"止盈仍未固化"）销账——S14 起 8 天，入场/止损/仓位/风控全齐，离场终于闭环。

## 设计决策（用户拍板：移动止盈）

三种形态（固定目标 / 移动 / 分批）选了 **trailing**：A 股强势票卖飞的代价 > 被洗出的代价（002636 涨停拉法若 +5% 固定止盈就下车了）；且日K序列在手，S13 回测面天然能校准参数。

## 语义（与止损同骨架：watch 唤醒裁决，不自动卖）

- **触发**：现价市值 ≤ 持有期峰值×(1−5%) **且回撤线高于止损线**（锁利位有效才接管）。第二个条件是关键：浮盈不足时 trailing 线低于止损线，止损线兜底——不需要额外的"武装门槛"参数，两条线的几何关系自然完成切换。
- **峰值跟踪**：`PositionState.peak` 进 broker 持仓（`notePrice(code, price)` 只上抬不下压，watch checkStops 每轮喂最新快照价）。买入成交价起步（加仓不压低历史峰）；清仓重买 = 新持有期重置。**进程重启后 peak 回落为买入成交价**（盘中峰值不留账）——fail-loose 但保守：线变低不易误触发。
- **去重**：止损/止盈共用 `riskWoke` 一把阀（同 code 每日至多唤醒一次）——都破时止损语义优先（先判止损，更严重）。
- **边界继承**：T+1 可卖才叫、熔断静默、唤醒文案区分两种触发（浮亏破位 vs 峰值回撤带浮盈现值）。

## 诚实边界（记档）

- **回测校准未做**：5% 对称起步是拍的（与止损对称），S13 replay 引擎是轮动调仓形态，个股级 trailing 校准需要逐票持有模拟——参数校准挂 P2，先跑起来攒对账数据。
